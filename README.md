# xianyu-radar · 闲鱼雷达

> 闲鱼低价新品监控 + 描述过滤 + 自动生成待付款订单的常驻后台工具（Windows）

**当前状态：设计阶段（[DESIGN_v5](design/DESIGN_v5.md) 待实施）**

## 它是做什么的

闲鱼雷达是一个常驻后台运行的 Windows 自动化工具，帮你**第一时间发现低价新品**，但把最终交易决定权留给你：

```text
自动发现 → 自动筛选 → 自动生成待付款订单 → 邮件通知 → 人工确认 → 人工决定是否付款
```

## 核心功能

- **关键词监控**：多个监控任务独立配置，按关键词在闲鱼搜索，按"最新发布"排序
- **智能扫描**：从最新商品开始扫描，遇到上一轮已见商品即停止，支持扫描上限保护
- **三层过滤**：商品身份过滤（空盒/配件/求购/租赁等）→ 规则词表（损坏/引流）→ AI 语义判断（可选）
- **自动拍单**：对通过过滤且价格低于阈值的商品，自动创建**待付款订单**
- **绝不自动付款**：拍下即停在待付款状态，由你人工确认商品、卖家、价格后决定是否付款
- **邮件通知**：新商品、拍单结果、AI 异常、登录失效、风控暂停等事件实时通知

## 核心安全边界

| 边界 | 说明 |
|---|---|
| 不自动付款 | 程序可以提交订单，但永远不触碰任何支付按钮 |
| 不重复拍单 | 同一 `item_id` 只能自动提交一次 |
| UNKNOWN 保护 | 提交后状态无法确认 → 禁止再次提交，通知人工核查 |
| 多规格不自动拍 | 检测到多规格商品仅通知，不自动下单 |
| 首次运行只建基线 | 第一次启动只记录不拍单，防止误拍历史商品 |
| 不硬闯风控 | 验证码/风控 → 立即暂停并邮件告警 |

## 技术选型

- Python 3.12 + `uv` 环境管理
- Playwright（Chromium）真实浏览器模拟人工操作，不做接口逆向
- 规则词表 + AI 大模型（DeepSeek）双层判断
- JSON / JSONL 存储，`pytest` 测试

├── config/           # 配置 + 词表
├── browser/          # 浏览器层（会话/搜索/详情/下单）
├── core/             # 核心逻辑（过滤/去重/拍单决策/通知）
├── scripts/          # probe 实测 / 手动登录
├── data/             # 运行时数据（已 gitignore）
└── tests/
